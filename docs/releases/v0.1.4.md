# MiniMax H3 工作台 v0.1.4

本次更新重点修复 Windows 用户反馈的 ComfyUI“检测通过但生成失败”。

## 修复

- 配置检测与连接测试现在同时验证 H3 原生节点和五个必需模型文件。
- 生成任务提交前会再次预检，并明确显示缺少的文件名及对应 ComfyUI 目录。
- 修正配置指南中已经不存在的“选择 ComfyUI 根目录”说明。
- 模型下载继续使用官方直达链接，安装包不捆绑模型权重。

## 新功能

- 左下角新增“检查更新”按钮。
- 启动时自动检查最新的公开 GitHub Release。
- 检测到新版本后显示醒目提醒，并可直接打开官方下载页。

说明：旧版本尚不具备自动更新提醒，需要手动安装一次 v0.1.4；从 v0.1.4 起，后续发布新版本时软件会自动提示。
